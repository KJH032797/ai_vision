# Day03 Rule Analysis

## FastAPI 실시간 확장 실습

### 실습 흐름
- 아이폰의 OctoStream RTSP Camera Server 영상을 FastAPI/OpenCV가 받아 브라우저로 전달했다.
- 브라우저에서 사용자가 검사 영역(ROI)을 직접 선택했고, 그 영역에 기존 Day03 Area Ratio 규칙을 적용했다.
- 이 사각형은 자동 검출 BBox가 아니라 수동으로 지정한 고정 ROI다.

### 확인된 실행 내용
- 사용자 확인: OctoStream RTSP 최초 연결 후 실시간 화면과 ROI/판정 기능이 동작했다.
- 사용자 확인: 수정 후 아이폰에서 앱을 껐다 다시 켠 뒤에도 재연결이 잘 됐다.
- 촬영 조건: 1080p, 30fps. 촬영 거리는 성인 남성이 앉아 팔을 앞으로 뻗었을 때보다 한두 뼘 짧은 정도였다. 정확한 거리는 측정하지 않았다.
- 사용자 관찰: 병뚜껑이 있을 때 정상 출력이 나왔지만, 병뚜껑을 제거한 뒤에도 OK가 나온 경우가 있었다.
- 사용자 관찰: 정상 판정에서 병뚜껑이나 병을 제거해도 OK가 유지된 경우가 있었고, NG 판정에서는 병뚜껑이 있어도 NG가 유지된 경우가 있었다.
- 사용자 관찰: 판정이 늦게 바뀌는 때가 있었으며, 카메라 위치를 조금 조정하자 판정이 정상적으로 바뀐 경우가 있었다.
- 사용자의 당시 판단: 병뚜껑 유무보다 ROI 박스 크기와 카메라 위치가 판정에 더 큰 영향을 준 것처럼 보였다. 이는 실험 당시의 육안 관찰이며, ROI 비율이나 판정 지연 시간의 수치는 기록하지 않았다.
- 병 자체를 제거한 경우와 병뚜껑만 제거한 경우 모두 확인했으나, 각 조건별 반복 횟수와 수치 기록은 없다.
- 자동 테스트 `python -m pytest tests/test_inspector.py -q`는 `2 passed`였다. 실제 아이폰 재연결 성공은 별도 실기기 확인으로 기록한다.

### Part 8 검증 결과 기록

| 조건 | 실제 장면 | 화면 결과/수치 | 상태 |
|---|---|---|---|
| 뚜껑 있음 | 사용자가 병뚜껑이 있는 장면을 확인 | 정상 출력이 나온 경우가 있었음. 반복 횟수·수치는 미기록 | 확인함, 정량 기록 없음 |
| 뚜껑 없음(병은 유지) | 병뚜껑을 제거하고 확인 | OK가 유지된 경우가 있었음 | 오판 사례 확인 |
| 병 제거 | 병과 뚜껑을 제거하고 확인 | 박스·카메라 위치에 따라 OK가 유지된 경우가 있었음 | 오판 사례 확인 |
| 병뚜껑 있음, 기존 NG 상태 유지 | 카메라·ROI 박스를 그대로 두고 병뚜껑을 둔 장면 | NG가 유지된 경우가 있었음 | 오판 사례 확인 |
| ROI/카메라 위치 조정 | 카메라 위치를 조금 움직여 확인 | 판정이 정상으로 바뀐 경우가 있었음. ROI 비율과 지연 시간은 미기록 | 위치·ROI 영향 관찰 |
| OctoStream 앱 재시작 후 재연결 | 앱을 껐다 다시 켠 뒤 재연결 | 사용자가 재연결이 잘 되는 것을 확인 | 확인함 |

### 촬영 조건 및 ROI 비교
- OctoStream 해상도/FPS: 1080p, 30fps.
- 촬영 거리: 성인 남성이 앉아 팔을 앞으로 뻗은 거리보다 한두 뼘 짧은 정도. 정확한 거리 측정값은 없다.
- 조명, 촬영 각도, 스마트폰과 병의 고정 여부: 별도 기록이 없어 미확인.
- ROI 크기/비율을 바꿔 비교했으나 비율 수치는 저장하지 않았고 현재 기억나지 않는다. 판정이 ROI 박스 크기와 카메라 위치의 영향을 받는 듯했다는 정성 관찰만 기록한다.

### 한계와 다음 확인
- 이 규칙은 병이 화면에 있는지 또는 병 위치가 ROI 안에 있는지를 독립적으로 검증하지 않는다.
- 실험에서 병 또는 뚜껑이 없어도 OK가 유지되거나, 뚜껑이 있어도 NG가 유지되는 사례가 관찰됐다.
- 카메라 위치를 바꾸자 판정이 달라진 사례가 있었지만, ROI 비율·Area Ratio·지연 시간은 기록하지 않아 원인을 수치로 확정할 수 없다.
- 병 위치와 ROI를 고정하고, 뚜껑 있음/없음 및 병 있음/없음 조건을 반복해 결과를 기록하면 원인을 더 분명하게 비교할 수 있다. 현재 수업 실험에서 수행하지 않은 반복 결과를 사후에 채워 넣지 않는다.

### 실시간 결과 파일 저장 여부
FastAPI 실시간 화면의 프레임, ROI 좌표, 판정 결과는 현재 파일로 저장되지 않는다. ROI 비율이나 실시간 판정값도 별도 기록으로 남지 않았다. `outputs/day03/batch/` 및 `reports/day03_inspection_results.csv`는 기존 Batch Test 결과이므로 이 실시간 실습 결과와 구분한다.
